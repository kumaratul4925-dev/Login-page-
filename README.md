# Page

 login page built using **HTML, CSS and JavaScript**.

## Project Preview

Login is a front-end login screen designed with a modern SaaS-style interface. It includes:

- Responsive layout for desktop and mobile
- Modern card-based UI
- Email validation
- Password validation
- Show/Hide password button
- Remember me checkbox
- Forgot password interaction
- Demo login button
- Success and error messages
- Small animations and hover effects
- No external JavaScript libraries

## Technologies Used

- **HTML5** — page structure
- **CSS3** — styling, responsive design and animations
- **JavaScript (ES6+)** — form validation and interactions
- **Google Fonts** — DM Sans and Manrope

## How to Run

1. Download or extract the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

### Recommended

If you use VS Code, install the **Live Server** extension and:

1. Right-click `index.html`
2. Select **Open with Live Server**

## Demo Login

The **Try demo login** button fills:

```text
Email: demo@example.com
Password: demo123
```

This is only a front-end demo. It does **not** connect to a real database or authentication server.

## Validation Rules

### Email
The email field:
- Cannot be empty
- Must follow a basic email format

### Password
The password:
- Cannot be empty
- Must contain at least 6 characters
